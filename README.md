# kiki motion studio

An immersive, full-frame backdrop and motion gallery. Minimal black and champagne styling, floating controls, adjustable room lighting, and a collection of 16 stills and four motion films.

## Preview locally

Run `python -m http.server 8080` in this folder, then open http://localhost:8080.

## Deployment

Static website: publish this repository root with any static hosting provider. No build step is required.

## Files

- `index.html`: page structure
- `style.css`: responsive styling
- `app.js`: collection, lighting, navigation, and fullscreen controls
- `assets/`: backdrop images, venue scene, and optimized video

Artwork and media remain the property of their respective owners. No reuse license is granted.

Videos autoplay in a continuous four-film playlist and can also be selected manually. Stills appear below the videos and remain on screen only when selected. Use the resume button to return to video playback.
